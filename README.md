# Colloqui scuola–famiglia

Pagina per prenotare un colloquio con il docente Kevin Carinci.

- Durata: 30 minuti.
- Pausa fra colloqui: 15 minuti.
- Disponibilità definite dal docente nell’area riservata.
- Prenotazioni condivise e blocco degli orari già occupati.
- Conferma, calendario personale e annullamento.
